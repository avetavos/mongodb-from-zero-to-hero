## Document model

| English | Thai Style | หมายเหตุ |
|---------|-----------|---------|
| document | document | หน่วยข้อมูลพื้นฐาน — ไม่แปลเป็น "เอกสาร" เพราะจะสับสนกับ documentation |
| collection | collection | กลุ่มของ document — เทียบเท่า table ใน relational DB |
| field | field | คีย์หนึ่งตัวใน document |
| BSON | BSON | binary encoding ของ JSON ที่ MongoDB ใช้เก็บข้อมูลจริง |
| `_id` / ObjectId | `_id` / ObjectId | primary key เริ่มต้นของทุก document |
| embedding | embed / การ embed | เก็บข้อมูลที่เกี่ยวข้องไว้ใน document เดียวกัน |
| referencing | reference / การ reference | เก็บ `_id` ของ document อื่นไว้แทนการ embed |

## Query & CRUD

| English | Thai Style | หมายเหตุ |
|---------|-----------|---------|
| query | query | ใช้ทับศัพท์ ไม่แปลเป็น "คิวรี" |
| filter | filter | เงื่อนไขที่ query ใช้จับคู่ document |
| operator (`$gt`, `$in`, ...) | operator | คีย์พิเศษขึ้นต้นด้วย `$` |
| projection | projection | การเลือกว่าจะคืน field ไหนกลับมา |
| upsert | upsert | update ถ้าเจอ, insert ถ้าไม่เจอ |
| operation | operation | คำกลาง ๆ สำหรับการกระทำหนึ่งครั้งบน database (ไม่แปลเป็น "การดำเนินการ") |

## Indexes & Aggregation

| English | Thai Style | หมายเหตุ |
|---------|-----------|---------|
| index | index | โครงสร้างข้อมูลที่เร่งความเร็ว query |
| compound index | compound index | index ที่สร้างจากหลาย field |
| ESR rule | กฎ ESR (Equality, Sort, Range) | ลำดับการจัด field ใน compound index |
| aggregation pipeline | aggregation pipeline | ลำดับของ stage ที่แปลง document ทีละขั้น |
| stage (`$match`, `$group`, ...) | stage | หนึ่งขั้นตอนใน aggregation pipeline |
| accumulator | accumulator | ฟังก์ชันสรุปค่าใน `$group` เช่น `$sum`, `$avg` |

## Transactions & Scaling

| English | Thai Style | หมายเหตุ |
|---------|-----------|---------|
| transaction | transaction | กลุ่มของ operation ที่ต้อง commit หรือ abort พร้อมกัน |
| write concern / read concern | write concern / read concern | ระดับการยืนยันความทนทาน/ความสดของข้อมูล |
| replica set | replica set | กลุ่มของ MongoDB instance ที่ถือสำเนาข้อมูลเดียวกัน |
| primary / secondary | primary / secondary | node ที่รับเขียน / node ที่คัดลอกข้อมูลมา |
| sharding | sharding | การกระจาย collection ไปหลาย shard เพื่อ scale การเขียน |
| shard key | shard key | field ที่ใช้ตัดสินว่า document อยู่บน shard ไหน |
| chunk | chunk | ช่วงของ shard key ที่ถูกกำหนดให้ shard หนึ่ง ๆ |

## เมื่อ **ไม่** ควรใช้ literal Thai translation

| หลีกเลี่ยง | ใช้แทน |
|------------|--------|
| เอกสาร (หมายถึง document) | document |
| คอลเลกชัน | collection |
| การดำเนินการ | operation (หรือ "ทำงาน" / "รัน" ถ้าหมายถึงกริยา) |
| ทำการ + กริยา (เช่น "ทำการ insert") | ตัดคำว่า "ทำการ" ออก ใช้กริยาตรง ๆ ("insert") |
| ชิ้นส่วน (หมายถึง shard/chunk) | shard / chunk |
